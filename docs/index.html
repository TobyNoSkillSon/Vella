MLX speech benchmarks

Every tested quantization, not just the app’s family picks. Click a heading to sort. Lower word-only/full-text errors and RAM are better; higher speed and punctuation/casing scores are better.

RAM means observed peak MLX allocation after warmup, in decimal GB. It is not file size, total process RAM, Activity Monitor memory, or a minimum Mac memory specification. Python/native memory and other apps need headroom; loaded server models may accumulate. Accuracy and speed use two passes. Memory uses a separate one-pass profile except Voxtral streaming: its peak comes from the completed two-pass timing run, as recorded in row provenance.

Full-text errors include capitalization and punctuation; this is the default sort, lowest first. They measure character edits against a written reference, not uniquely correct editorial style. Word-only errors count word edits and ignore case and punctuation. The two columns use different units: words versus characters. Punctuation/casing are conditional on aligned words; hover a row for coverage. Only three usable quotation clips: no reliable quotation ranking.

144 clips · 34 speakers · 20m 15s · clean English book reading from LibriSpeech-PC. Not spontaneous/noisy dictation, multilingual validation, or spoken paragraph commands. Warm speed excludes loading, HTTP and paste. Small score differences are not proof of general superiority.

Rows labeled “streaming” use native incremental input on the same corpus; other rows use batch inference. Streaming speed is accelerated compute throughput, not microphone-to-word latency. † marks a batch-benchmarked candidate outside the Dictation catalog. Picks refer to the row’s mode.
