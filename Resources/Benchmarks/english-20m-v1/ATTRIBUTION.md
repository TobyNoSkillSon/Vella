# English 20-minute test set

LibriSpeech by Vassil Panayotov, Guoguo Chen, Daniel Povey, and Sanjeev Khudanpur; derived from LibriVox recordings. Unedited cached FLAC audio and its reference text, selected round-robin across speakers.

Source: https://www.openslr.org/12

License: CC-BY-4.0, https://creativecommons.org/licenses/by/4.0/

Fixed multi-speaker subset of LibriSpeech test-clean. Read English, not conversational/noisy/multilingual dictation; not a full LibriSpeech score. Full clips are retained so reference text remains aligned.

Selection and per-file hashes are recorded in `manifest.json`.
